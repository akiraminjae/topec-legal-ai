# 사용자 매뉴얼 (USER_MANUAL)

## 1. 로그인

1. 관리자로부터 받은 이메일/사번과 초기 비밀번호로 로그인합니다.
2. 최초 로그인 시 비밀번호 변경 화면으로 자동 이동합니다. 10자 이상의 새 비밀번호로 변경하세요.
3. 관리자가 2단계 인증(TOTP)을 활성화한 경우 로그인 시 인증 앱의 6자리 코드를 함께 입력합니다.

## 2. 계약서 등록

1. 좌측 메뉴에서 **계약서 업로드**를 클릭합니다.
2. 계약명, 계약유형, **TOPEC 계약상 지위**(발주자/원사업자/수급사업자 등)를 정확히 선택합니다.
   이 값은 AI 분석의 가장 중요한 전제조건이므로 잘못 선택하면 위험판정이 반대로 나올 수 있습니다.
3. 상대방, 계약금액, 계약기간, 보안등급, 보존기간을 입력합니다.
4. 계약서 파일(PDF/이미지/DOCX/HWPX/HWP/TXT)을 첨부하고 **업로드 및 AI 검토 시작**을 클릭합니다.
5. 업로드 후 자동으로 문서 상세 화면으로 이동하며, 분석 진행 단계(파일검증→...→완료)가 표시됩니다.

## 3. 검토결과 확인

문서 상세 화면은 다음 탭으로 구성됩니다.

- **개요**: 계약 기본정보, AI 요약, 보고서 생성/다운로드
- **원문/조항**: 자동 분리된 조항 목록과 원문
- **위험분석**: 위험등급별로 정렬된 탐지 항목 — 클릭하면 사유, TOPEC 영향, 권고 대응, 관련 법령·판례를
  확인할 수 있습니다
- **수정안**: 최소/권고/보호강화 3단계 수정문구와 원문·수정안 비교
- **AI 질의응답**: 계약서와 사내 법률지식베이스를 근거로 자유롭게 질문
- **법무검토**: 법무검토 요청 및 진행상황 확인

모든 결과 화면 하단에는 "AI 1차 검토 결과이며 최종 법률판단을 대체하지 않는다"는 안내문이 항상
표시됩니다.

## 4. 수정안 사용

**수정안** 탭에서 각 수정문구를 검토한 뒤 **채택** 또는 **거절**을 선택할 수 있습니다. 채택 이력은
보고서 생성 시 반영됩니다.

## 5. 법무검토 요청

1. **법무검토** 탭에서 요청사항을 입력하고 **법무검토 요청**을 클릭합니다.
2. 법무담당자가 **법무 검토함** 메뉴에서 요청을 확인하고 담당자를 지정합니다.
3. 법무담당자가 검토의견을 작성하고 승인/보완요청/반려 중 하나로 처리하면 문서 상태가 갱신됩니다.

## 6. 보고서 출력

**개요** 탭에서 다음 보고서를 생성할 수 있습니다.

- 검토보고서(DOCX/PDF): 계약 개요, 위험분석, 수정안 비교가 포함된 전체 보고서
- 상대방 수정요청서(DOCX): 권고 수정안(STANDARD)만 담은, 상대방에게 바로 전달 가능한 문서

PDF 변환이 일시적으로 실패하면 DOCX 파일이 대신 제공되며 화면에 실패 사실이 표시됩니다.

## 7. 문서 삭제

**내 문서** 목록에서 본인이 등록한 문서를 선택해 삭제할 수 있습니다(관리자는 모든 문서 삭제 가능).
삭제 시 원본파일과 분석결과가 함께 제거되며, 삭제 이력은 감사로그에 남습니다. 업로드 시 선택한
보존기간이 지나면 시스템이 자동으로 삭제 처리합니다.

## 7.1 소송·분쟁 사건(여러 문서를 한 사건으로 통합관리)

준비서면·소장·답변서 등 여러 문서가 오가는 소송·분쟁은 문서를 하나씩 개별 업로드하는 대신
**소송·분쟁 사건** 메뉴에서 사건 단위로 통합관리할 수 있습니다.

1. **소송·분쟁 사건 → 새 사건 등록**에서 사건명을 입력합니다. 사건번호·법원·청구금액 등은 모를 경우
   비워둘 수 있습니다. 보안등급은 기본값이 "극비"이며, 극비 상태에서는 내부망 AI(LocalModelProvider)
   설정 전까지 사건 통합분석·AI 질의응답이 제한됩니다 — 바로 AI 분석을 쓰려면 보안등급을 낮추세요.
2. 사건 상세 화면의 **사건자료 일괄 업로드** 탭에서 여러 개의 PDF를 한 번에 선택하거나 끌어다
   놓습니다. 파일별로 문서유형(소장/답변서/준비서면 등)을 지정할 수 있으며, 지정하지 않으면
   "기타"로 분류됩니다(문서유형 자동판별 기능은 아직 없습니다 — 업로드 후 문서 상세화면에서
   수정 가능).
3. **일괄 업로드 시작**을 누르면 파일이 순서대로 업로드되고, 각 파일은 독립적으로 분석됩니다. 한
   파일이 실패해도 나머지 파일 처리에는 영향이 없으며, 실패한 파일만 따로 다시 시도할 수 있습니다.
4. **문서 목록** 탭에서 각 문서의 개별 분석상태를, **사건 타임라인** 탭에서 문서를 업로드 순서로
   확인합니다(※ 문서 작성일·제출일 등을 본문에서 자동으로 구분 추출하는 기능은 아직 없어, 타임라인은
   실제 사건 경과일이 아닌 업로드 순서 기준입니다).
5. 모든 문서의 개별 분석이 끝나면 **사건 통합분석** 탭에서 통합분석을 실행합니다. 문서별 분석결과를
   종합해 사건 개요·상대방 주장·TOPEC 입장·핵심 쟁점·누락 및 미대응사항·종합 대응방향을 제공합니다.
   새 문서를 추가하면 다시 실행해 최신 내용을 반영하세요.
6. **사건 AI 질의응답** 탭은 이 사건에 업로드된 문서에서만 근거를 찾습니다(다른 사건 자료는 검색되지
   않습니다).
7. **대응문서 작성** 탭에서 통합분석 결과를 바탕으로 준비서면 초안 또는 경영진 보고 요약을 생성할 수
   있습니다. 생성된 초안은 AI 1차 초안이므로 담당 변호사·법무담당자의 검토 없이 그대로 제출해서는
   안 됩니다.

## 8. 주의사항

- 본 시스템은 TOPEC 내부 업무지원 목적으로만 사용하며, 외부 고객에게 결과를 그대로 전달하지 않습니다.
- AI/규칙엔진이 근거를 찾지 못한 경우 "현재 연결된 법률자료에서는 직접 확인되는 근거를 찾지
  못했습니다"로 표시됩니다 — 이 경우 임의로 판례를 만들어내지 않았다는 의미이므로, 법무담당자 확인이
  필요합니다.
- CONFIDENTIAL 등급 문서는 내부망 AI가 설정되지 않은 경우 분석이 제한될 수 있습니다.
