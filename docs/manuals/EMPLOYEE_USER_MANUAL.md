# 1. 시작하기

## 1.1 시스템 소개

TOPEC 사내 법률검토 AI 시스템은 계약서와 소송·분쟁 관련 문서를 업로드하면 AI가 1차로 위험조항을 탐지하고, 관련 법령·판례를 찾아주고, 수정안과 검토보고서를 만들어주는 사내 전용 도구입니다.

> **중요**: AI 검토 결과는 어디까지나 1차 참고자료입니다. 최종 법률판단은 반드시 법무담당자 또는 외부 법률전문가의 확인을 거쳐야 합니다.

## 1.2 접속 방법

- **웹 브라우저**: `https://app.topecai.co.kr` 접속 (사내망 여부와 무관하게 접속 가능, Chrome/Edge 최신버전 권장)
- **PC/모바일 설치형 앱(PWA)**: 위 주소로 접속한 뒤 브라우저 주소창의 설치 아이콘(또는 메뉴 → "앱 설치"/"홈 화면에 추가")을 누르면 일반 프로그램처럼 설치되어 아이콘으로 바로 실행할 수 있습니다.
- **안드로이드 설치형 앱(.apk)**: 시스템 관리자에게 `TOPEC-Legal-AI.apk` 파일을 전달받아 휴대폰에 설치할 수 있습니다. Play 스토어를 거치지 않으므로 설치 시 "출처를 알 수 없는 앱 설치 허용"이 필요합니다(§11 참고).

# 2. 회원가입 및 로그인

## 2.1 신규 회원가입

1. 로그인 화면에서 **"계정이 없으신가요? 회원가입"**을 클릭합니다.
2. 아래 정보를 입력합니다.
   - 사용자 ID (사번)
   - 이름
   - 휴대폰 번호
   - **회사 이메일** (TOPEC 임직원 회사 이메일만 가입 가능합니다)
   - 비밀번호 (10자 이상) / 비밀번호 확인
3. **"가입 신청"**을 누르면 입력한 회사 이메일로 인증 메일이 발송됩니다.
4. 메일의 인증 링크를 클릭하면 이메일 인증이 완료됩니다.
5. **관리자 승인**이 필요합니다. 관리자가 승인을 완료하기 전까지는 로그인이 되지 않습니다. 승인 여부는 시스템 관리자(법무팀)에게 문의하세요.
6. 승인이 완료되면 로그인 화면에서 로그인할 수 있습니다.

> 인증 메일이 오지 않았다면 가입 신청 완료 화면의 **"인증 메일 다시 받기"** 버튼으로 재발송할 수 있습니다. 스팸함도 함께 확인해 주세요.

### 기본 권한 안내

가입이 승인되면 기본적으로 아래 기능을 사용할 수 있습니다.
- 대시보드
- 내 문서
- 계약서 업로드 및 AI 검토

**소송·분쟁 사건** 메뉴와 **법무 검토함** 메뉴는 업무상 필요한 경우 관리자가 승인 시점에 별도로 권한을 부여해야 보입니다. 필요하신 경우 가입 시 또는 이후에 관리자에게 요청하세요.

## 2.2 로그인

1. 로그인 화면에서 **이메일 또는 사번**과 **비밀번호**를 입력합니다.
2. 관리자가 계정에 2단계 인증(OTP)을 설정해 둔 경우, **2단계 인증 코드** 입력란이 추가로 나타납니다. 인증 앱(Google Authenticator 등)에 표시되는 6자리 코드를 입력하세요.
3. 로그인에 5회 이상 연속 실패하면 계정이 일시적으로 잠깁니다. 이 경우 관리자에게 문의하세요.

## 2.3 비밀번호 변경

- 관리자가 계정을 직접 생성해 임시 비밀번호를 받은 경우, **최초 로그인 시 비밀번호 변경 화면으로 자동 이동**하며 변경 전까지 다른 화면을 사용할 수 없습니다.
- 이후에도 좌측 상단 프로필 영역이 아닌, 주소창에 `/change-password`로 직접 이동하거나 관리자에게 재설정을 요청해 언제든 비밀번호를 바꿀 수 있습니다. (현재 비밀번호 + 새 비밀번호(10자 이상) + 새 비밀번호 확인 입력)

# 3. 화면 구성

로그인하면 왼쪽에 사이드바 메뉴가 나타납니다. 보유한 권한에 따라 보이는 메뉴가 다릅니다.

| 메뉴 | 설명 | 표시 조건 |
|---|---|---|
| 대시보드 | 내 문서 현황 요약, 통계, AI 사용량 | 전체 사용자 |
| 내 문서 | 내가 업로드한 문서 목록 | 전체 사용자 |
| 계약서 업로드 | 새 계약서/소송문서 업로드 화면 | 전체 사용자 |
| 소송·분쟁 사건 | 사건 단위 통합관리 | 소송·분쟁 사건 담당 권한 보유자 |
| 법무 검토함 | 배정된 법무검토 요청 처리 | 법무담당자(LEGAL_REVIEWER) |
| 관리자 / 리소스 모니터링 / 로그 기록 | 시스템 관리 | 시스템관리자만 (§ 관리자 매뉴얼 참고) |

화면 오른쪽 위에는 로그인한 사용자 이름, 소속 부서, 보유 역할이 표시되며 **로그아웃** 버튼이 있습니다.

# 4. 대시보드

대시보드는 로그인 후 처음 보이는 화면으로, 내 업무 현황을 한눈에 보여줍니다.

- **상단 통계 카드**: 검토 중 문서 수 / 완료된 문서 수 / 법무검토 대기·진행 수 / 고위험 계약 수(빨간색으로 강조)
- **위험등급 분포**: 내가 올린 문서들의 위험등급(매우 높음~적정) 비율을 도넛 차트로 표시
- **문서유형별 건수**: 계약유형별로 몇 건씩 올렸는지 막대그래프로 표시
- **나의 최근 계약검토**: 최근 업로드한 문서 10건 목록(클릭하면 상세화면으로 이동)
- **나의 AI 사용량**: 오늘 / 이번 달 / 전체 누적 기준으로 내가 사용한 AI 호출 건수와 입력·출력 토큰 수 (본인 것만 표시됩니다)

# 5. 계약서·소송문서 업로드 및 AI 검토

## 5.1 새 문서 업로드

좌측 메뉴 **"계약서 업로드"**(또는 사건 상세화면의 "사건자료 일괄 업로드")를 클릭합니다.

1. **검토 종류** 선택: 계약서 검토 / 소송·분쟁 문서 검토
2. **계약명(또는 문서명)** 입력
3. **계약서 검토**를 선택한 경우:
   - 계약유형(하도급, 설계·감리·CM 용역, 물품구매·공급, SaaS, NDA, MOU 등)
   - TOPEC 계약상 지위(발주자/수급자 등)
   - 계약금액, 계약 시작일/종료일 (선택)
4. **소송·분쟁 문서 검토**를 선택한 경우:
   - 문서유형(소장/답변서/준비서면/항소상고이유서/결정문/판결문/내용증명·최고장/기타)
   - TOPEC의 소송상 지위(원고/피고/보조참가인 등)
   - 사건번호, 법원 (아는 경우에만 입력)
5. 상대방, 프로젝트명/현장명 (선택)
6. **보안등급** 선택 — 아래 §5.2 참고
7. 문서 보존기간 선택
8. 추가 검토요청사항(선택, AI에게 특별히 봐달라고 요청하고 싶은 내용)
9. **파일 첨부**: PDF, 스캔 이미지(JPG/PNG), DOCX, HWPX, HWP, TXT 지원. 여러 파일을 한 번에 선택하거나, 선택창을 다시 열어 추가로 첨부할 수 있습니다. 첫 번째로 첨부한 파일이 **AI 분석의 기준(주 파일)**이 되고, 나머지는 참고 첨부파일로 함께 저장됩니다.
10. **"업로드 및 AI 검토 시작"**을 누르면 자동으로 문서 상세화면으로 이동하며 분석이 시작됩니다.

## 5.2 보안등급 이해하기

| 등급 | 설명 |
|---|---|
| 일반(사내) | 기본값. 사내 통상 업무 문서 |
| 중요 | 민감도가 있는 문서 |
| 극비 | 외부에 노출되면 안 되는 매우 민감한 문서. 소송·분쟁 문서는 극비를 권장 |

> **주의**: **"극비" 등급 문서는 사내 내부망 AI가 별도로 구축되어 있지 않으면 AI 분석 자체가 진행되지 않습니다**(외부 AI로 절대 전송하지 않는 보안정책 때문입니다). 실제로 극비 수준의 보안이 필요하지 않은 문서를 실수로 극비로 올렸다면, 문서 상세화면에서 보안등급을 낮추고 재분석하면 됩니다(§6.7 참고).

## 5.3 분석 진행 상태 확인

업로드 후 문서 상세화면에서 진행률 게이지와 단계별 상태(파일검증 → 텍스트추출 → OCR → 구조화 → AI분석 → 완료)를 실시간으로 확인할 수 있습니다. 화면은 자동으로 갱신되므로 새로고침할 필요가 없습니다.

# 6. 문서 상세화면 사용법

내 문서 목록 또는 대시보드에서 문서명을 클릭하면 상세화면으로 이동합니다. 문서 종류(계약서/소송문서)에 따라 탭 구성이 조금 다릅니다.

## 6.1 개요 탭

- 문서 요약(AI가 정리한 전체 요약, 종합 위험등급)
- 듀얼 AI 교차검토 결과(설정된 경우 — 서로 다른 AI 두 개가 교차 검증한 의견 표시)
- 첨부파일 목록 및 다운로드
- **검토보고서 생성**: DOCX 또는 PDF 형식으로 검토보고서를 만들고 다운로드할 수 있습니다.
- **공유하기(🔗)**: 텍스트 복사, .txt 파일 다운로드, Word/PDF 다운로드, 카카오톡 공유 중 선택 가능

## 6.2 원문/조항 탭 (소송문서는 "원문/쟁점")

문서를 조항(또는 쟁점) 단위로 나눠서 원문을 보여줍니다.

## 6.3 위험분석 탭 (소송문서는 "쟁점 분석")

AI가 탐지한 위험조항(또는 상대방 주장에 대한 대응 방향) 목록을 위험등급별로 확인할 수 있습니다. 각 항목에는 문제 요약, 사유, TOPEC에 미치는 영향, 권장 조치, 관련 법령·판례 근거가 함께 표시됩니다.

## 6.4 수정안 탭 (계약서만)

위험조항에 대해 AI가 제안하는 수정 문구(원문 대비 수정본, 수정 사유)를 확인할 수 있습니다.

## 6.5 AI 질의응답 탭

채팅 형태로 해당 문서에 대해 자유롭게 질문할 수 있습니다. AI는 문서 원문과 사내 법률지식자료, 실시간 법령·판례 검색 결과를 근거로 답변합니다.

## 6.6 법무검토 탭

법무담당자의 정식 검토가 필요하다고 판단되면 요청사항을 적고 **"법무검토 요청"**을 누르세요. 배정된 법무담당자가 "법무 검토함" 메뉴에서 확인 후 검토의견을 남깁니다.

## 6.7 분석이 실패했을 때 대처법

문서 상단에 빨간색 배너로 **실제 실패 사유**가 표시됩니다(예: "CONFIDENTIAL 등급 문서는 내부망 AI 설정이 없으면 분석할 수 없습니다"). 사유를 확인한 뒤:

- **재분석 시도** 버튼: 일시적인 오류였다면 다시 시도합니다.
- **보안등급 변경 후 재분석**(문서를 올린 본인 또는 관리자만 가능): 실수로 등급을 너무 높게 설정한 경우, 드롭다운에서 알맞은 등급을 선택하고 버튼을 누르면 등급 변경과 재분석이 한 번에 진행됩니다.

그 외 원인으로 계속 실패한다면 관리자 또는 법무담당자에게 문의하세요.

## 7.1 문서 삭제

**본인이 올린 문서는 직접 삭제할 수 있습니다.** 목록의 각 행 또는 문서 상세화면 우측 상단에서 **"삭제"** 버튼을 누르고 확인하면 삭제됩니다. 삭제된 문서는 복구할 수 없으니 신중히 진행하세요. (다른 사람이 올린 문서는 삭제할 수 없으며, 시스템관리자만 예외적으로 모든 문서를 삭제할 수 있습니다.)

# 8. 소송·분쟁 사건 관리 (권한 보유자)

"소송·분쟁 사건" 메뉴는 개별 문서가 아니라 **사건 단위**로 여러 문서를 묶어서 관리하는 기능입니다. 이 메뉴는 관리자가 "소송·분쟁 사건 담당" 권한을 부여한 사용자(및 법무담당자·부서관리자·경영진·시스템관리자)에게만 보입니다.

## 8.1 새 사건 등록

**"새 사건 등록"**을 눌러 사건명, 사건유형/분쟁유형, 사건번호, 법원, TOPEC의 소송상 지위, 상대방/대리인 정보, 청구금액, 주요 일자, 보안등급, 사건 개요와 확인할 쟁점을 입력합니다. 보안등급은 기본값이 "극비"이며, 실제 AI 분석을 바로 쓰려면 등급을 낮춰야 합니다(§5.2 참고). 등록 후 파일은 다음 화면에서 일괄 업로드합니다.

## 8.2 사건 상세화면 탭 구성

| 탭 | 기능 |
|---|---|
| 사건자료 일괄 업로드 | 사건 관련 문서를 여러 개 한 번에 업로드 |

# 10. 모바일/PWA/안드로이드 앱 설치

## 10.1 PWA (PC/모바일 공통)

`https://app.topecai.co.kr` 접속 후 브라우저 주소창 오른쪽의 설치 아이콘을 클릭하거나, 모바일 브라우저 메뉴에서 **"홈 화면에 추가"** 또는 **"앱 설치"**를 선택하면 일반 앱처럼 아이콘이 생성됩니다.

## 10.2 안드로이드 설치형 앱(.apk)

1. 시스템 관리자에게 `TOPEC-Legal-AI.apk` 파일을 전달받습니다(카카오톡 '나에게 보내기', 이메일, USB 등).
2. 휴대폰 설정에서 **"출처를 알 수 없는 앱 설치"**를 허용합니다(최초 1회, 기기/설치 방식에 따라 문구가 다를 수 있음).
3. 다운로드한 apk 파일을 눌러 설치합니다.
4. 설치 후 실행하면 브라우저 주소창 없이 일반 앱처럼 전체화면으로 열립니다.

# 11. 자주 묻는 질문 / 유의사항

- **Q. 회원가입했는데 로그인이 안 돼요.** → 이메일 인증(메일함 확인) → 관리자 승인, 두 단계가 모두 끝나야 로그인됩니다. 관리자에게 승인 여부를 문의하세요.
- **Q. 다른 사람이 올린 문서가 안 보여요.** → 정상입니다. 이 시스템은 "본인이 올린 문서는 본인만 볼 수 있다"는 원칙을 기본으로 하며, 관리자·부서관리자(같은 부서)·법무담당자(배정된 건)·경영진(극비 제외)만 예외적으로 접근할 수 있습니다.
- **Q. 극비 문서인데 AI 분석이 안 돼요.** → 의도된 보안정책입니다. §5.2, §6.7을 참고해 보안등급이 실제로 극비여야 하는지 확인하세요.
- **Q. AI가 준 결과를 그대로 써도 되나요?** → 안 됩니다. AI 결과는 1차 참고자료이며, 중요 계약·고위험 조항·소송문서는 반드시 법무담당자 확인을 거쳐야 합니다.
- **Q. 계정을 잘못 만들었어요 / 탈퇴하고 싶어요.** → 본인이 직접 탈퇴하는 기능은 없습니다. 관리자에게 요청하세요.
